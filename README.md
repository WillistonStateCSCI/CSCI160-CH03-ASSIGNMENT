# CSCI160-CH03-EXERCISES
About Programming Exercises From Java Illuminated Book by Anderson and Franceschi
## Q03_50 Instructions  
Write a program that reads two words representing passwords from the keyboard and outputs the number of characters in the smaller of the two.  For example, if the two words are *open* and *sesame*, then the output should be *4*, the length of the shorter word, *open*.  
### Q03_50 Test 1  
**Input:**  
open  
sesame  
**Output:**  
The length of the shorter password is 4  
### Q03_50 Test 2  
**Input:**  
abrakadabra  
alakazam  
**Output:**  
The length of the shorter password is 8  
## Q03_51 Instructions  
Write a program that prompts the user for a domain name.  Your program should then concatenate that name with *www.* and *.com* in order to form an Internet domain name and output the result.  Fir instance, if the name entered by the user is *yahoo*, then the output will be *www.yahoo.com*.  
### Q03_51 Test 
**Input:**  
google  
**Output:**  
The Internet domain is www.google.com

## Q03_56 Instructions  
Write a program that reads a full name (first name and last name) from the keyboard as a single line; you should expect the first name and the last name to be separated by a space.  Retrieve and output the first and last names.  
### Q03_56 Test 
**Input:**  
Buddy Holly   
**Output:**  
Your full name is Buddy Holly  
Your first name is Buddy  
Your last name is Holly
